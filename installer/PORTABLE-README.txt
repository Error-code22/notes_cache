Foluma 1.0.6 — Windows x64 folder build
=========================================

This is the no-installer build. Unzip the whole folder somewhere you can
write to, then run notes_cache.exe.

Do not move notes_cache.exe out of the folder on its own. It needs the DLLs,
data folder, and Flutter assets beside it.

Settings and notes are still stored per Windows user (in the normal app-data
locations). This folder is portable, but app data is not yet stored inside it.
A future release will add a true portable-data mode.

For the installed version, use Foluma-Setup-1.0.6.exe instead.
